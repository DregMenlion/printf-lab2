# Домашнее задание к работе 2

## Условие задачи

Стоимость погонного метра красного шелка составляет **X** золотых.  
Сколько заплатил Грей за ткань для своей бригантины, если общая площадь парусов на ней **S м²**, а ширина ткани в рулоне **L см**.

В программе используются значения:

- `X = 8` — стоимость 1 погонного метра красного шелка;
- `S = 240` — общая площадь парусов;
- `L = 120` — ширина ткани в рулоне.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Задать исходные данные:
   - `X = 8` — стоимость 1 погонного метра красного шелка (золотых).
   - `S = 240` — общая площадь парусов (м²).
   - `L = 120` — ширина ткани в рулоне (см).
3. Перевести ширину ткани из сантиметров в метры:
   - `width = L / 100`
4. Вычислить необходимую длину ткани:
   - `length = S / width`
5. Вычислить стоимость ткани:
   - `cost = length * X`
6. Вывести исходные данные и результаты расчета.
7. **Конец**

## 2. Реализация программы

Программа реализована на языке **C**.

Для вычисления используются следующие формулы:

```c
width = L / 100.0;
length = S / width;
cost = length * X;
```

Код индивидуального задания:

```c
void individual()
{
    double X = 8;
    double S = 240;
    double L = 120;

    double width = L / 100.0;
    double length = S / width;
    double cost = length * X;

    printf("Стоимость 1 погонного метра красного шелка: %.0f золотых.\n", X);
    printf("Общая площадь парусов: %.0f м2.\n", S);
    printf("Ширина ткани в рулоне: %.0f см.\n", L);
    printf("Потребуется %.2f погонных метров ткани.\n", length);
    printf("Грей заплатил %.2f золотых.\n", cost);
}
```

## 3. Результаты работы программы
