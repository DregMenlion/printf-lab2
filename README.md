\# Домашнее задание к работе 2



\## Условие задачи



Стоимость погонного метра красного шелка составляет X золотых.

Определить, сколько заплатил Грей за ткань для своей бригантины,

если общая площадь парусов равна S м², а ширина ткани в рулоне L см.



Для расчета используются значения:



\- X = 8 золотых

\- S = 240 м²

\- L = 120 см



\## 1. Алгоритм и блок-схема



\### Алгоритм



1\. Начало.

2\. Задать исходные данные:

&#x20;  - X = 8 — стоимость одного погонного метра ткани;

&#x20;  - S = 240 — площадь парусов;

&#x20;  - L = 120 — ширина ткани в сантиметрах.

3\. Перевести ширину ткани из сантиметров в метры:



&#x20;  `width = L / 100`



4\. Найти необходимую длину ткани:



&#x20;  `length = S / width`



5\. Найти стоимость ткани:



&#x20;  `cost = length \* X`



6\. Вывести количество ткани и стоимость.

7\. Конец.
